# 背书刷题神器 · 微信小程序

一个刷题 + 背书二合一的微信小程序。**任意文本格式导入即用**，自动识别单选 / 多选 / 判断 / 填空 / 解答五类题型，支持选项乱序、题目乱序、多错题集、AI 交互背书。原生小程序实现，**零第三方依赖、无云开发**，离线可用（AI 功能除外）。

## 二、运行项目（详细步骤）

1. 打开微信开发者工具 → 右上角「+」/ 首页「导入项目」；
2. **目录**选择本文件夹（包含 `app.json` 的那一层）；
3. AppID 会自动读取为 `wx6882ac9f972953c1`（如提示登录账号不符，请切换登录为绑定该测试号的微信号）；

5. **首次启动自动导入内置内容**：豆包题库 11 章（共 130 题）、全题型示例题库、示例背书《静夜思》。可在「题库」「背书」两个 Tab 里直接看到。

## 三、刷题

### 3.1 导入题目（三种方式）

入口：首页「导入刷题文本」或 题库页「＋ 导入题库」。

| 方式 | 操作 |
|---|---|
| ① 直接粘贴 | 把题目文本粘进输入框 → 点「识别预览」→ 可删除识别错的题 → 起名保存 |
| ② 微信文件导入 | 把 txt / md / json / **docx** 文件发到微信「文件传输助手」→ 小程序里「📎 从微信文件导入」→ 从聊天选择文件 |
| ③ 内置示例 | 点「⭐ 填充示例」体验全部题型 |

### 3.2 支持的格式（任意排版都能识别）

```
(单选题, 2.0 分) 世界上最大的海洋是( )
A. 大西洋 B. 印度洋 C. 太平洋 D. 北冰洋
答案：C
解析：……（可选）

(多选题, 3.0 分) 下列属于哺乳动物的是( )
A. 鲸鱼 B. 鲨鱼 C. 蝙蝠 D. 企鹅
答案：AC

(判断题, 2.0 分) 光在真空中的传播速度约为每秒 30 万公里。
答案：对

(填空题, 2.0 分) 中国的首都是____。
答案：北京
（多空：题目____和____，答案：(1) xxx (2) yyy）

(简答题, 5.0 分) 简述光合作用的主要产物。
答案：有机物和氧气。
```

同时兼容：`1.【单选】题目`、`（单选）题目`、`【判断】题目`、Markdown、带题号的纯文本、学习通/豆包等考试系统导出文本。选择题的选项可以一行内、每行一个、带 `A.` 前缀、带 `（1）（2）` 前缀、甚至**没有任何前缀**；`我的答案：xxx` 会被自动忽略；无参考答案的题会提示自行判断。

### 3.3 开始刷题

题库 → 点题库卡片 → 「开始刷题」→ 刷题设置页：

- **题型**：单选/多选/判断/填空/解答 自由勾选；
- **题量**：全部 / 5 / 10 / 20 / 30 / 50 题；
- **乱序题目**：打乱出题顺序；
- **乱序选项**：选择题选项打乱——**字母会按显示位置重新编号（最上面永远是 A）**，判分按选项文字内容进行，乱序不影响对错；
- **答对自动跳下一题**：打开后答对约 1 秒自动进入下一题；关闭则手动点「下一题」（可自行选择，设置页可设默认值）；
- **错题去向**：选择本组答错题进入哪个错题集（可新建）。

答题规则：

- 单选/判断：点选项立即判分；
- 多选：勾选后点「确认答案」；
- 填空：每个空一个输入框，逐空判分，支持多可接受答案（用 `|` 分隔）；
- 解答题：写下答案点「提交答案」，**不自动判对错**，只展示参考答案供自查；如需收录可点「＋ 加入错题集」；
- 答错会显示正确答案与解析；无参考答案的题（如部分考试导出）作答后自行判定对错。

### 3.4 结果页

得分（解答题不计入得分）、按题型正确率、答题回顾（逐题展开看你的答案/正确答案/解析）、「再来一组」按相同设置重刷。

## 四、错题集

- **多个错题集**：错题本 Tab → 「＋ 新建」，可改名、删除、清空；
- 刷题时选择「错题去向」，答错自动进错题集（同题重复答错累计次数）；
- **错题集内刷题**：错题本 → 点错题集 → 「刷错题」；
- **做对 N 遍自动移除**（自由选择）：设置页滑条 0~10，默认 3。连续做对 3 遍自动移出（答错清零重计）；0 = 永不自动移除，可手动「移出」；
- 每道错题显示"做错次数 + 连续做对进度条"。

## 五、背书

### 5.1 导入内容

入口：首页「导入背书内容」/ 背书 Tab「＋ 导入内容」。支持任意文本：`# 标题` 分章节、`1. 2. 3.` 列要点、`问：xxx / 答：xxx` 生成问答卡、普通段落。

### 5.2 三种背书模式

- **浏览**：分章节阅读；问答卡点击翻面显示答案；
- **挖空自测**（离线可用）：自动把关键内容挖空——横线数量与答案字数一致、输入框旁标有「X字」提示；填写后「检查答案」逐空判分；
- **AI 互动背书**（需配置 AI 接口，见下）：
  - **AI 考我**：AI 围绕内容出题，你作答后 AI 判分、给正确答案和讲解，再出下一题；
  - **AI 挖空**：AI 把关键句改成填空题考你；
  - **自由提问**：就这段内容随便问，AI 只根据内容回答、不编造。

### 5.3 AI 接口配置（设置页）

默认 **DeepSeek**：地址 `https://api.deepseek.com/v1`、模型 `deepseek-chat`，只需填 **apiKey**（在 platform.deepseek.com 申请）。任何 OpenAI 兼容接口都可替换（OpenAI / 通义 / 智谱 / Moonshot 等）。

> 开发者工具里需勾选「详情 → 本地设置 → **不校验合法域名**」；真机使用时需在小程序后台配置 request 合法域名。设置页有「测试连接」按钮。

## 六、真机调试

1. 电脑与手机连接**同一 Wi-Fi**；
2. 工具点「真机调试」→ 手机微信扫码；
3. 常见报错：
   - `41002, appid missing`：项目 AppID 不是真实 AppID。本项目已配置为测试号 `wx6882ac9f972953c1`；若你换账号登录，需在「详情 → 基本信息」改成你账号下的 AppID；
   - 手机一直连不上：检查同一网络、关闭电脑防火墙对工具的限制，或改用「预览」扫码。

## 七、常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 编译报错（WXML） | WXML 属性里不能用 `&&`（须写成嵌套 wx:if）、不能有未转义特殊字符——本项目已全部规避 |
| 模拟器白屏 / appLaunch timeout | 点「编译」重编；或 工具→清除缓存→全部清除 后重启工具 |
| `Unexpected token ﻿ in JSON at position 0` | 文件被写入了 UTF-8 BOM（PowerShell `Set-Content -Encoding UTF8` 会引入）。本仓库所有文件已确保无 BOM；请勿用上述命令改写项目文件 |
| 导入后识别不理想 | 复制一段原始文本发在 Issue 里；删除个别错题可在识别预览里点 ✕ |
| 数据太多卡顿 | 建议按章节分批导入；「设置 → 清空所有数据」可重置并重新导入内置内容 |

## 八、技术说明

- **docx 解析**：`utils/zip.js` 内置纯 JS 的 ZIP 容器解析 + DEFLATE 解压，小程序内直接抽取 `word/document.xml`，无需任何第三方库；
- **解析容错**：`utils/parser.js` 已针对 130 道真实考试导出题逐题验证（选项缺前缀、选项挤一行、多空填空、`答案:DF` 连写、`我的答案` 混入、无题型标签的题目等均可识别）；
- **判分安全**：选择题按**选项文字内容**判分，选项乱序与字母重编号不影响对错；
- **数据**：全部本地缓存（题库 / 背书内容 / 错题集 / 设置 / 刷题会话断点续刷），无网络也可使用。
